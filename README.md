# Valeward Capital — website

Static HTML/CSS/JS. No build step required to deploy, no dependencies, no framework.
Upload the contents of `/site` to any host (Netlify, Vercel, Cloudflare Pages, S3, or plain
Apache/nginx) and it runs.

```
site/
├── index.html               Homepage — hand-maintained
├── approach.html            ┐
├── portfolio.html           │
├── why-multifamily.html     │
├── investor-experience.html │  generated by _build/build.py
├── about.html               │
├── insights.html            │
├── faq.html                 │
├── invest.html              │
├── disclosures.html         │
├── privacy.html             ┘
├── robots.txt
├── sitemap.xml
├── assets/
│   ├── css/styles.css       Full design system — every token lives here
│   ├── js/main.js           Interaction layer, commented module by module
│   ├── js/agent.js          Investor assistant (see the root README)
│   ├── img/                 Photography and generated stills
│   └── video/hero.mp4       Optimised hero footage (2.1MB)
└── _build/build.py          Page generator — do not deploy this folder
```

## Running it locally

```bash
python -m http.server 8899 --directory site
```

Then open `http://localhost:8899`. Open it over `http://`, not by double-clicking the file —
`file://` will not load the stylesheet correctly.

## Editing pages

**Homepage:** edit `index.html` directly.

**Every other page:** edit the entry in `_build/build.py`, then regenerate:

```bash
python _build/build.py
```

The header, footer, disclosure block and page shell live in that one file so they can never
drift apart across ten pages. Editing a generated `.html` directly works, but the next build
overwrites it — change `build.py` instead.

## Adding photography

Each image position currently renders an illustrated SVG scene. Drop a real photo into
`assets/img/` with the matching filename and it takes over automatically — no code change.
If a file is absent, the illustration stays. Nothing breaks either way.

| Filename | Where | Suggested shot |
|---|---|---|
| `hero-interior.jpg` | All interior page heroes | Wide, dark, low detail — it sits behind text |
| `property-2…4.jpg` | Portfolio cards | 16:10 exteriors, consistent time of day |
| `why-1.jpg` | Why Multifamily feature | 4:5 vertical, architectural |
| `og-home.jpg` | Social sharing | 1200×630 |

Already supplied: `hero.mp4` + `hero-poster.jpg` (homepage hero),
`principles-bg.jpg` (homepage section 2), `carla-kiernan.jpg` (About).

Export at 2× the display size, then compress to WebP or AVIF and add `srcset` before launch.

## The design system

Everything is tokenised at the top of `styles.css`. To reskin the site, change the tokens —
not the components.

- **Colour** — sampled from the logomark. Gold (`--gold`) is reserved for the primary CTA.
  Using it anywhere else weakens every button on the site.
- **Type** — Cinzel (display; the VALEWARD wordmark) + Jost (body; the CAPITAL subline).
  Cinzel sets lowercase as petite caps, so it takes positive tracking and smaller sizes.
  Long-form text never goes in Cinzel.
- **The arch** — `--arch: 999px 999px 4px 4px`. The signature radius. Applied to the timeline
  markers, image frames, the assistant launcher and the closing outline.
- **Motion** — one curve, `--ease-out`. Durations: `--d-press` 140ms, `--d-ui` 220ms,
  `--d-reveal` 760ms.

### Reusable classes
`.section--ink` / `--paper2` / `--blush` for section backgrounds · `.arch-figure` for arched
imagery · `.card`, `.property`, `.tcard` · `.steps` / `.step` · `.accordion` / `.acc` ·
`.criteria` / `.criterion` for the spec grid · `.calc` for the return model · `.migration` for
the tile map · `.total-return` for the blended figure · `.reveal` (add `data-stagger` to a
parent to auto-index children) · `.reveal-arch` for the doorway wipe · `[data-count]` for
animated numbers · `[data-magnetic]` for the pull effect.

## Accessibility

Built in, please keep it: skip link, single `<h1>` per page, sequential headings, visible focus
rings, ARIA on the accordion and mobile menu, 44px minimum touch targets, `prefers-reduced-motion`
honoured throughout, hover effects gated to fine pointers, and tables with captions and scoped
headers. Verified at 375px, 768px, 1024px and 1440px with no horizontal overflow.

## Before you launch

Both forms are demonstrations — they validate and show a success state but send nothing.
Connect them to your CRM, add server-side validation and spam protection.

**Every figure, name, property and testimonial on this site is an illustrative placeholder** and
must be replaced with verified information before publication. See the pre-launch checklist in
`../STRATEGY.md` — the securities-counsel review and the 506(b) vs 506(c) determination come first.
